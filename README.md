# Shot

一个 macOS 菜单栏截图工具。没有网络代码，没有第三方依赖，源码很短，可以自己读完再用。

## 功能

- 全局快捷键（默认 ⌃⌥A 选区、⌃⌥W 窗口、⌃⌥S 全屏），可在 Settings 里修改
- 截图后屏幕冻结，在原位置框选；选区固定后可用手形工具移动，拖动四角和四边的手柄调整大小
- 窗口截图：鼠标移到窗口上即高亮，点一下选中
- 标注：矩形、椭圆、直线、箭头、画笔、荧光笔、文字（回车换行，⌘回车或 Esc 结束）、序号（自动递增的圆圈数字）、马赛克
- 标注可拖动、可删除；粗细分 S/M/L 三档，样式可选实线、虚线、填充；选中标注时改粗细和样式会直接作用到它
- 画笔和荧光笔：按住 ⇧ 拖动，笔迹锁成水平或竖直的直线
- 回车复制并关闭，P 贴图，T 识别文字
- 识别文字（OCR）：框选后点工具栏的文字图标或按 T，把选区里的文字（中英文）识别出来复制到剪贴板并关闭；识别的是截图本身，不含标注；没识别到文字时提示音一声、覆盖层保留。用系统自带的 Vision 框架，完全离线
- ⌘Z 撤销、⌘⇧Z 重做；方向键微调选中的标注（没有选中标注时微调选区），⇧加方向键一次 10 点
- 复制到剪贴板，或保存到自选文件夹（默认 `~/Pictures/Shot`）；格式可选 PNG、JPG、HEIC，文件名可用模板（`{date}`、`{time}`、`{n}` 序号）
- 工具栏里的拖出图标：把截图直接拖进聊天窗口、Finder、文档，不用先复制
- 贴图（Pin）：点工具栏的图钉或按 P，选区（含标注）变成浮在所有窗口上面的小窗，位置不变。拖动移动；缩放：触控板双指捏合、滚轮、键盘 +/-，触控板双指轻点两下或按 0 恢复原大小；⌘C 复制（边框变蓝并提示 Copied）、⌘S 保存；双击或 Esc 关闭；右键可复制、保存、缩放、调透明度；菜单栏有「Close All Pins」
- 贴剪贴板里的内容：菜单栏「Pin from Clipboard」把剪贴板里的图片（别处复制的、网页上的、别的截图）或文字直接贴成悬浮小窗。图片原大小居中，超过屏幕就缩到放得下；文字显示在白底卡片里（最宽 560，最多 5000 字，太长截断），放大缩小时字号跟着变，⌘C 复制的是文字，⌘S 存成 .txt；剪贴板里什么都没有时这一项是灰的。贴图的其他操作和截图贴图一样
- 收纳箱（Stack）：鼠标移到贴图上，右上角出现收纳按钮，点一下就把这张贴图（图片、文字或链接）收进收纳箱。也可以不贴出来，直接把选中的文字、网页链接、图片（网页上的图或图片文件）拖到屏幕上的口袋图标上收纳：拖到图标上时图标垫上底板，松手就收进去；其他类型的文件不收。不想拖的话（比如只有触控板）：先 ⌘C 复制，再按住 Option 点一下口袋图标，或者按「收纳剪贴板」的快捷键（默认 ⌃⌥C，Settings 里可改；菜单栏有「Store Clipboard in Stack」），剪贴板里的文字、链接或图片就收进去了。屏幕上常驻一个小口袋图标（陶土色，口袋里露出手帕角，右上角的数字是收纳的条数），默认在右上角，可以按住拖到任何位置（包括别的显示器），位置会记住；点一下图标展开收纳箱，再点收起。快捷键（默认 ⌃⌥X，Settings 里可改）、菜单栏「Show / Hide Stack Icon」和 Settings 里的开关控制的是整个图标的出现和隐藏，图标隐藏时展开的收纳箱也一起收起。展开的卡片挂在图标下面，图标靠近屏幕底部时往上展开，靠近左边时和图标左边对齐，拖动图标时它跟着走。收纳箱像钱包里的卡片一样竖着叠放：最旧的在最上面，每张只露出顶上一条，最新的在最前面完整显示，鼠标移到哪一张，它下面的往下让开、这一张完整展开。最多放 10 条，满了挤掉最旧的；相同内容不会重复收纳，再收一次只是挪到最前面。每张卡片最上面有一条横条（pad），可以打红、黄、绿三种颜色的标签（像红绿灯）：鼠标指到卡片上，横条左边出现三个小圆点，点一个就打上这个颜色，再点同一个取消；叠放时露出的就是这一条，所以一眼能看出颜色。打标签不会收起收纳箱，同样的内容再次收纳时标签保留。点卡片复制，拖出到别的 App 里，鼠标移上去可以「贴回屏幕」或删除。点了卡片（复制）或卡片上的按钮（贴回屏幕、删除）之后，收纳箱会自己收起，只剩图标；点屏幕上任何其他位置也一样（点图标本身是展开或收起）。收纳箱没展开时收纳了东西（图标隐藏着也一样），它会在图标的位置自动出现 2 秒再收起。收纳的内容放在临时文件夹，Shot 退出或重新启动时清空；「Close All Pins」不影响收纳箱
- 延时截图：快捷键（默认 ⌃⌥D）按 Settings 里选的时长（3、5、10 秒，默认 5）倒计时，结束后冻结屏幕并自动选中上次的选区（还没有记录时是普通选区），倒计时中按数字键 0 到 9 可从该秒数重新倒计时（0 为 10 秒），再按一次快捷键、按 Esc 或点倒计时可取消；菜单栏「Other Delays」可单次选别的时长。用来截菜单、悬浮提示
- 「Repeat Last Region」快捷键（默认 ⌃⌥R）：冻结屏幕后直接选中上次确认的区域，适合在同一位置反复截图
- 可选：复制后若干秒自动清空剪贴板、开机自启、隐藏菜单栏图标（再打开一次 App 即可呼出设置）
- 默认保留 Retina 分辨率；Settings 里可改用 1x 以降低内存

## 构建与安装

需要 Xcode 命令行工具（Swift 5.9+），macOS 27 及以上（不兼容更旧的系统）。

```sh
./build.sh                      # 生成 Shot.app（本机临时签名）
cp -R Shot.app /Applications/
```

首次截图时 macOS 会请求「屏幕录制」权限，授权后重新打开一次 Shot。

macOS 按签名认 App。没有证书时 `build.sh` 用临时签名，每次重新构建签名都不同，系统会当成新 App 再要一次权限。只需做一次，就能让重新构建后权限保持有效：

1. 打开「钥匙串访问」，菜单「钥匙串访问 → 证书助理 → 创建证书…」
2. 名称填 `Shot Local`，身份类型选「自签名根证书」，证书类型选「代码签名」，点「创建」
3. 重新运行 `./build.sh`，看到 `signed with "Shot Local"` 即可

如果之前授权过临时签名的版本，先清掉旧记录再授权：

```sh
tccutil reset ScreenCapture local.shot
```

## 项目结构

```
Sources/Shot/
  main.swift            程序入口、菜单栏图标和菜单
  Capture.swift         抓屏流程：冻结屏幕、检测窗口
  Session.swift         每次截图的子进程：启动、通信、退出
  Countdown.swift       延时截图的倒计时
  Pin/PinWindow.swift   贴图窗口与管理（图片贴图、文字贴图、收纳按钮）
  Stack/
    StackStore.swift    收纳箱的数据：临时文件夹、内容指纹去重、最多 10 条
    StackWindow.swift   收纳箱窗口（子进程）：缩略图、点击复制、拖出、贴回、删除
    StackIcon.swift     右上角的小口袋图标和条数角标（常驻进程里）
    TagPicker.swift     卡片横条上的红黄绿三个标签圆点
    RoundButton.swift   圆形小按钮
    StackDrop.swift     拖到图标上的内容怎么收（文字、链接、图片）
    Warm.swift          暖色调色板（奶油、蜜桃、沙色、陶土）
  Annotation.swift      标注的数据模型、绘制与点击检测
  Overlay/
    Overlay.swift       覆盖层窗口的创建与关闭
    OverlayView.swift   框选、移动与拉伸选区、标注、工具栏
    OverlayLayers.swift 截图图层与标注图层
    Handle.swift        选区四角和四边的手柄
    DragHandle.swift    把截图拖出覆盖层的图标
  Shortcuts.swift       全局快捷键的保存与注册
  SettingsWindow.swift  设置窗口
  Preferences.swift     保存目录、Retina 等设置项
  Clipboard.swift       复制到剪贴板与自动清除
  Output.swift          保存格式、文件名模板、不重名
  Ocr.swift             识别选区里的文字（Vision）
icon/                   图标脚本与图标素材
build.sh                构建并签名 Shot.app
```

## 实现说明

- 抓屏使用系统自带的 `/usr/sbin/screencapture`（只用来抓一张整屏图，选区、窗口检测与标注都是 Shot 自己做的）。
- 图标由 `icon/make-icon.swift` 绘制，`build.sh` 会调用它并用 `iconutil` 合成 `.icns`。`icon/` 里还有浅色/深色预览和分层素材。
- 每次截图都在一个独立的子进程里完成（贴剪贴板里的内容用 `--pin-clipboard`、收纳箱用 `--stack`、从收纳箱贴回用 `--pin-item`，同样是子进程）：菜单栏常驻进程用参数 `--capture` 启动自己的另一份，子进程冻结屏幕、显示覆盖层，关闭后退出（有贴图时等最后一张贴图关闭再退出），截图占用的内存随进程退出全部还给系统，常驻进程不持有任何截图。剪贴板自动清除的计时由常驻进程负责。
