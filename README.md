# Shot

一个 macOS 菜单栏截图工具。没有网络代码，没有第三方依赖，源码很短，可以自己读完再用。

## 功能

- 全局快捷键（默认 ⌃⌥A 选区、⌃⌥W 窗口、⌃⌥S 全屏），可在 Settings 里修改
- 截图后屏幕冻结，在原位置框选，可移动选区
- 标注：矩形、椭圆、直线、箭头、画笔、文字、马赛克；标注可拖动、可删除
- 复制到剪贴板，或保存到自选文件夹（默认 `~/Pictures/Shot`）
- 可隐藏菜单栏图标（再打开一次 App 即可呼出设置）

## 构建与安装

需要 Xcode 命令行工具（Swift 5.9+），macOS 13+。

```sh
./build.sh                      # 生成 Shot.app（本机临时签名）
cp -R Shot.app /Applications/
```

首次截图时 macOS 会请求「屏幕录制」权限。因为是临时签名，每次重新构建后权限会失效，需要在系统设置里重新授权。

## 实现说明

- 抓屏使用系统自带的 `/usr/sbin/screencapture`（只用来抓一张整屏图，选区与标注是 Shot 自己画的）。
- 图标由 `make-icon.swift` 绘制，`build.sh` 会调用它并用 `iconutil` 合成 `.icns`。`icon/` 里是浅色/深色预览和分层素材。
